# Gokul Narayana — Portfolio

Personal portfolio of **Gokul Narayana Maddala**, full-stack and Flutter developer based in Hyderabad.

**Live site:** https://gokulnarayana-30.github.io/gokul-portfolio/

Featured work: Doggyji, Forum Labs, Spencheck and ViZenLink.

Built as a single static page (HTML, CSS and vanilla JavaScript) with no build step. The project mockups are drawn in code, not screenshots.

## Run locally
